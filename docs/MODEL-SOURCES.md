# Premade model candidates

Researched October 3, 2026. Candidates only: no downloads or purchases made, and no third-party mesh integrated yet. Keep author attribution alongside any imported asset.

## TX-130 priority

LarsH: Clone Wars TX-130, listed as free downloadable, CC Attribution, 7.2k triangles / 4.4k vertices. Author describes creating it with Blender and Substance Painter. Promising game-asset candidate; inspect actual downloaded files, texture packing and separable moving parts before adoption. Direct retrieval through the research browser returned 403, so the downloadable payload and file formats have not been verified.
https://sketchfab.com/3d-models/tx-130-saber-class-fighter-tank-clone-wars-5507d2f2313e4fb7aa6d9d18f97d70e0

PanMann: Clone Wars TX-130 with interior and APC variant, actual .blend files, listed $28.99 Standard Use License. Exterior is 64k vertices, interior another 100k; requires removing interior and substantial reduction for SC2. Not purchased. Confirm the asset-sharing terms for packaged multiplayer distribution before using it.
https://www.artstation.com/marketplace/p/7677N/tx-130-saber-class-fighter-tank-with-interior-apc-variant-star-wars-the-clone-wars
