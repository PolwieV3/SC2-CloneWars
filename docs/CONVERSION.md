# Conversion foundation

`inventory/conversion-matrix.csv` seeds actual base blueprint IDs and roles for Republic and CIS planning. It includes buildings, special units and internal helpers; rows are not all player-buildable skirmish choices. `unit-variants.csv` retains DLC/campaign variants for reconciliation. Proposed identities remain design suggestions except the implemented TX-130 name. The matrix is generated by `tools/inventory.py`; update proposals in that tool before regenerating it.

UEF remains the internal faction key/category for Galactic Republic. Cybran remains the internal key/category for CIS. Keep faction ordering, starting ACUs/engineers, factory build lists and research categories. Change labels/art later; changing internal keys now would break references.

The actual base Cybran roster has no UCL0101 tank equivalent. Do not invent that ID to place an AAT. Decide whether AAT should visually replace an existing ground unit after reviewing that unit's role. The initial Loyalist proposal is a single B2 visual, not a multi-entity squad mechanic.

Suggested early assets: TX-130 for Rock Head, V-19 for Wasp, Y-wing for Eagle Eye, LAAT/i for Broadsword; CIS Vulture for Gemini and HMP for Renegade. Gemini must keep its combined fighter/bomber behavior. Separate transport and gunship roles remain separate even if their artwork is related. AT-TE for Fatboy II is provisional: its experimental role and weapon arrangement need a deliberate visual fit. Hailfire has two possible artillery/missile candidates; select one before asset work.

## Asset pipeline questions

Models are `.win.scm`; animations `.win.sca`; textures include `.win.dds` and `.dds`. A file inventory does not prove that a particular Blender importer/exporter supports SC2's variant. First round-trip one model in the dev copy, preserving skeleton, muzzle bones, LODs, scale and materials. Do not assume a Forged Alliance exporter works.

Audio references use `SC2/SC2/.../snd_...` event names; 11 sound-bank files were found outside gamedata. `references.csv` indexes cues, but event-to-bank mapping and replacement tooling remain unverified. Start with one weapon cue once the model pipeline works.

`research-nodes.csv` records observed IDs, costs, category filters, prerequisites and buff references from text research definitions, including variants. Future renames must preserve costs, prerequisite links, categories and buff effects. `research-files.csv` locates layout, simulation and effect sources.

## Inventory interpretation

All archive entries are listed with archive provenance, sizes and CRCs. Source references are lexical observations, not a resolved runtime graph. Repeated source/runtime copies and DLC/campaign shadow variants are intentional. `references.csv` weapon rows include label/category observations; weapon numeric balance has not been changed or exhaustively resolved. Model and texture paths can be engine-inferred rather than explicitly written in a blueprint.

The active baseline is now the Steam-verified base game + DLC. The former baseline with third-party content is preserved only under `local/history/`. Fallback localization names and source defaults still need checking against final in-game values, including research upgrades and active DLC.
